# Лабораторная работа №4

## Вариант 16. Модель парикмахерской

### Основа работы

Лабораторная работа №4 выполнена на базе результата лабораторной работы №1.

Сохранен и переиспользован общий код:

- `src/domain` — доменные сущности модели
- `src/application` — бизнес-логика системы
- `src/infrastructure` — JSON-репозиторий

Для ЛР4 добавлен веб-интерфейс, при этом CLI из ЛР1 сохранен и продолжает работать с тем же общим кодом и тем же файлом данных.

## Предметная область

Программная система моделирует работу парикмахерской, оказывающей услуги по стрижке и уходу за волосами.

### Важные сущности варианта

- парикмахерская
- клиент
- парикмахер
- инструменты
- услуги
- зеркало
- стул

### Операции варианта

- запись клиента на услугу
- проведение стрижки
- проведение укладки
- консультация по уходу за волосами
- оплата услуги
- управление записями клиентов

## Что реализовано в ЛР4

Веб-приложение реализовано на `Flask`.

Через веб-интерфейс доступны все возможности модели из ЛР1:

- добавление клиента
- добавление парикмахера
- просмотр списка услуг
- добавление инструмента
- добавление зеркала
- добавление стула
- создание записи на услугу
- завершение записи
- оплата услуги
- просмотр всех записей и фильтрация по клиенту
- отмена записи

Интерфейс также показывает текущее состояние модели:

- список клиентов
- список парикмахеров
- список услуг
- список инструментов
- список зеркал
- список стульев
- список записей с их статусами, деталями выполнения и оплатой

## Общий код для ЛР1 и ЛР4

Требование о выделении общего кода выполнено следующим образом:

1. Вся предметная модель и бизнес-логика находятся в `src/domain`, `src/application`, `src/infrastructure`.
2. CLI-интерфейс находится в `src/presentation/cli_handlers.py`.
3. Веб-интерфейс находится в `src/presentation/web_app.py`.
4. `main.py` и `app.py` используют один и тот же bootstrap (`src/bootstrap.py`) и создают один и тот же `SalonManager`.

Таким образом, CLI и web работают поверх одного общего кода.

## Хранение данных

Состояние системы сохраняется в файл `salon_data.json`.

В JSON сохраняются:

- клиенты
- парикмахеры
- инструменты
- услуги
- зеркала
- стулья
- записи

## Используемые статусы записи

- `booked`
- `completed`
- `cancelled`

## Запуск CLI

```powershell
py -3 main.py
```

## Запуск веб-приложения

Сначала установить зависимости:

```powershell
py -3 -m pip install -r requirements.txt
```

Запуск:

```powershell
py -3 app.py
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5000
```

## Запуск тестов

```powershell
py -3 -m unittest discover -v
```
