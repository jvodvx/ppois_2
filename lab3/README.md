# Pac-Man Lab 3 Scaffold

Minimal pygame scaffold for laboratory work variant 1.

## Run

```powershell
py -m pip install -r requirements.txt
py -m src.main
```

## Project layout

- `config/app.json` - window and gameplay settings
- `config/colors.json` - color palette
- `config/audio.json` - audio asset paths and volumes
- `config/levels/level1.json` - first map layout
- `src/game/` - source code
